# Problem 12

For any integer $k \geq 4$, there exists a constant $c_k > 0$ such that as $N \to \infty$, if $\mathcal{A}_N$ is a subset of the primes up to $N$ containing no nontrivial arithmetic progressions of length $k$, then the relative density $|\mathcal{A}_N| / \pi(N)$ is $O(\exp(-(\log \log \log N)^{c_k}))$.
