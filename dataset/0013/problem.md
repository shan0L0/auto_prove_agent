# Problem 13

For any prime $p$ and any integer $n \ge 5$, the alternating group $A_n$ is not a finite group of minimal order among all finite groups $G$ that contain a Sylow $p$-subgroup $P$ and an element $x \in G \setminus P$ such that every element in the coset $Px$ has order a power of $p$.
