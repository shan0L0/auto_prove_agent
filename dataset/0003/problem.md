# Problem 3

For each positive integer n, let F_n = {A_d : 1 ≤ d ≤ n}, where A_d = {d, 2d, 3d, ..., ⌊n/d⌋ d}. For any finite family F of finite subsets of ℕ, let m(F) be the least integer M such that there exist integer shifts t_A with the translated sets t_A + A (A ∈ F) pairwise disjoint and all contained in some interval of length M. Then, as n → ∞, one has m(F_n) = Θ(n^(3/2) / log n).
