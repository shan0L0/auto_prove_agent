# Problem 1

For any real numbers γ₁, γ₂, γ₃, γ₄, γ₅ with 28/29 < γᵢ < 1 for each i = 1,2,3,4,5, there exists a natural number N such that every integer n ≥ N satisfying n ≡ 5 (mod 24) can be represented in the form n = p₁^2 + p₂^2 + p₃^2 + p₄^2 + p₅^2, where each pᵢ is a prime number and, for each i, there exists a positive integer mᵢ such that pᵢ = ⌊mᵢ^(1/γᵢ)⌋.
