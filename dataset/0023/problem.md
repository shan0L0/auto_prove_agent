# Problem 23

For any positive integer $k$ and integer $n \ge 2$, the $2$-adic valuation of $\sigma_k(n) = \sum_{d \mid n} d^k$ satisfies $\nu_2(\sigma_k(n)) \le \lceil \log_2 n \rceil$ if $k$ is odd, and $\nu_2(\sigma_k(n)) \le \lfloor \log_2 n \rfloor$ if $k$ is even.
