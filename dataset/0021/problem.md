# Problem 21

For a prime $p$, let $c_n(p) = |\{A \in M_n(\mathbb{F}_p) \mid \det(A) \text{ generates } \mathbb{F}_p^\times\}| / p^{n^2}$, and let $c(p) = \inf_{n \ge 1} c_n(p)$. Then $\inf_{p \text{ prime}} c(p) = 0$.
