# Problem 32

Let $\rho \in [-1, 1]$ be a real number, and define the function $f : \mathbb{R} \to \mathbb{R}$ by $f(u) = \exp(-u^2/6) ((1-\rho^2) + \rho^2 u^2)^{1/3}$. If $|\rho| \leq 1/\sqrt{3}$, then $f$ has a unique local maximum at $u=0$. If $|\rho| > 1/\sqrt{3}$, then $f$ has exactly two local maxima, which are located at $u = \pm \sqrt{3 - 1/\rho^2}$.
