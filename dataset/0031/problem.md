# Problem 31

For any integers $n > r > 1$, let $m = \lfloor n/r \rfloor$. If $S$ is a set of $n$ irrational numbers, then the number of $r$-element subsets of $S$ whose elements sum to a rational number is at most $m \binom{n-m}{r-1}$.
