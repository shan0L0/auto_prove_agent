# Problem 22

Let $S = \{n^2 : n \in \mathbb{N}\}$, where $\mathbb{N}$ denotes the set of non-negative integers. For every set $A \subseteq \mathbb{Z}$ with positive upper Banach density, the set $A - A + S$ contains a Bohr set.
